## About the project

LifeHub is an ongoing personal project designed to bring different areas of everyday life into one connected platform. The idea is to create a personal operating system where users can manage areas such as productivity, health, fitness, nutrition, sleep, goals, habits, tasks, finance and learning from a single interface. I am developing the project iteratively, expanding both its functionality and visual design over time.

## Key features

**Dashboard**

A central overview that brings important information and progress from across LifeHub together in one place.

**Health & Fitness**

Dedicated areas for tracking and managing health, fitness and personal wellbeing.

**Nutrition & Sleep**

Tools and dashboards designed to help users monitor nutrition and sleep as part of their wider routine.

**Goals & Habits**

Systems for setting longer-term goals and building consistent habits through daily progress.

**Tasks & Productivity**

A productivity area for organising tasks and keeping track of things that need to be completed.

**Finance & Learning**

Additional sections for managing personal finances and keeping track of learning and development.

## Technical highlights

- Responsive interface built with HTML and CSS
- Interactive functionality implemented with JavaScript
- Reusable interface patterns across different sections of the application
- Dashboard-style layouts using cards and widgets
- Dark and light visual themes
- Designed as a modular platform that can be expanded with additional features over time
- Challenges & solutions

The main challenge with LifeHub is its scale. Rather than building one isolated feature, I am designing a platform made up of many interconnected areas. This means I need to think about consistency, navigation, reusable components and how information should be presented across the application. I am approaching the project iteratively, developing individual sections while keeping the wider structure of the platform in mind.

LifeHub is still actively in development. The current focus is on expanding the individual sections of the platform while refining the overall interface and user experience.
